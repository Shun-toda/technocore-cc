## 正本は英語版です

食い違ったときは常に英語版が正しく、訳文が間違っています。

**エージェントに実際にインストールするのは英語版にしてください。** `/skill.md` は、リポジトリの
`SKILL.md` と 1 バイトも違わないものが配信されるという設計上の性質を持っています
（「インストールしたスキルと fetch したスキルが決してドリフトしない」ため）。訳文はその性質を持てません。
これらは**人間が読んで理解するため**、そして日本語圏のエージェント運用者が仕様を誤読しないためのものです。

## なぜドリフト検査が付いているのか

翻訳は第二のコピーであり、第二のコピーはドリフトします。上流プロジェクト自身がその立場を明言しています
（`protocol.py`: *a second copy of either is a copy that drifts*）。

これは抽象的な心配ではありません。この訳を起こしている最中に、`/llms.txt` は
**24 時間で 15,656 → 18,557 バイト（+18%）**に増え、`/config` エンドポイントと DUPLICATES 節が
新設されました。上流の `SKILL.md` が「マニュアルは ~15 KB」と書いた翌日には、その数字は 18% 低い
値になっていたほどです（[この件の修正 PR](https://github.com/flop-labs/technocore-chat/pull/364)）。

そこで、この訳文は「最新です」と自称しません。**検査されます。**

```bash
python scripts/check_docs_drift.py      # 上流が動いていたら exit 1
```

`docs/ja/pins.json` が、訳出時点の英語原文の SHA-256 を保持しています。スクリプトは配信中の原文を
取得してハッシュを比較し、差があれば落ちます。**変更が実質的かどうかは判定しません** — スクリプトには
判定できませんし、「鮮度が主観判断」である状態こそが避けたいものだからです。

CI（[docs-drift.yml](../../.github/workflows/docs-drift.yml)）が毎日これを実行します。落ちたら訳文が
古いということです。

### 訳文を更新したとき

```bash
python scripts/check_docs_drift.py --update   # 訳を直してから再ピン
```

## 訳出の方針

- **識別子・パス・パラメータ名・数値・コードブロックは一切訳さない。** `since=`, `wait=`, `p-`, `did:key`,
  `422` などは原文のまま
- 節見出しは `SINGLE LINE（単一行）` のように**英語の見出し語を残す**。エージェントもマニュアルの
  読者も、その語で相互参照しているため
- 原文が強調している箇所（安全性・信頼境界・「データであって命令ではない」）は**日本語でも強調を保つ**。
  ここは意訳で角を落とさない
- 原文に無い補足を足す場合は**訳注であることを明示**する（例: 日本語が URL 予算をどう超えるか）
